# publishing this

GitHub shows a README on your profile when it lives in a repo named **exactly your username**.

## 1. create the repo

```bash
gh repo create shadezie --public --description "profile"
```

## 2. push this folder

```bash
git init -b main
git add .
git commit -m "profile readme"
git remote add origin https://github.com/shadezie/shadezie.git
git push -u origin main
```

## 3. turn on the contribution grid

The snake animation is generated by `.github/workflows/snake.yml` into an `output`
branch. It runs automatically every 12 hours and on every push, but the first run
needs a nudge:

```bash
gh workflow run "generate contribution grid" --repo shadezie/shadezie
```

Until that first run finishes, the "the grid" image in the README will be broken.
That's expected. Check it with:

```bash
gh run list --repo shadezie/shadezie --limit 3
```

If the action fails with a permissions error, go to
`Settings → Actions → General → Workflow permissions` and select
**Read and write permissions**.

## notes

- **`assets/banner.png`** is the X banner, resized to 1600px, referenced with a
  relative path so it travels with the repo.
- **No third-party stats cards.** `github-readme-stats` was returning 503 and the
  activity-graph instance was returning 402 when this was built, and the streak
  card would have published "current streak: 0" on your profile. The snake reads
  the same grid without putting weak numbers in a box.
- **"Include private contributions on my profile"** is on, which is what makes the
  grid worth showing — it takes the public view from 34 contributions to 96. If
  you ever turn it back off, the snake goes sparse and the section is worth cutting.
- One placeholder left: the TEC link (`theesportsclub.gg`) in the `now` section.

## the artwork

`assets/process-*.svg` and `assets/inspect-*.svg` are generated, not hand-drawn.
The source is `assets/generate.py` — edit the constants at the top (colours, the
`STEPS` list, the readout rows) and re-run it:

```bash
python3 assets/generate.py
```

The scatter uses a fixed random seed, so the art is identical on every run.
Both pieces have a light and a dark variant with transparent backgrounds, swapped
by `<picture>` on GitHub's theme.
